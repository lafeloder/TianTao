# Watchlist maintenance boundaries

For Top5RR and EuropePostdocs weekly maintenance, the user authorizes updates to paper/vacancy records, their evidence, dates and derived counts only.

- Preserve the existing page modules, layout, styles, headers, acknowledgements, filters, interactive charts, lists/tables and pagination.
- Do not simplify the pages or remove modules during a data refresh. Do not treat a stripped-down repository version as approval to discard the established interface.
- Do not modify `src/`, public UI assets or site configuration for a weekly refresh unless the user explicitly requests that UI change.
- Keep the fixed author roster, six-journal scope, original Finance Top5 author denominator and local-only workbook policy.
- If the user explicitly requests a UI correction, make only that correction and retain the latest verified watchlist data.

The full watchlist interface was restored at the user's explicit request on 2 November 2026 from the version before commit `f4d2b0a48de3f7f1e8cc62ad372cd40f5ab2c95f`.
